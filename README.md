# LOST FREQ 🎧

**Tune into the unknown.**

LOST FREQ is a music discovery website that helps you find your next obsession with a single click. Discover music across genres, languages, and eras — one random song at a time.

## ✨ Features

- 🎲 **Random Discovery** — Discover a random song with one click.
- 🌍 **Music Across Genres** — Explore a manually curated collection of tracks.
- 🎵 **YouTube Integration** — Open the selected song directly on YouTube.
- 🌅 **Cinematic Background** — An immersive, looping highway video background.
- 📱 **Simple Interface** — A minimal, distraction-free discovery experience.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- JSON
- YouTube links

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/lost-freq.git
   ```

2. Open the project folder in VS Code.

3. Run `index.html` using a local development server, such as the **Live Server** extension.
